## 1. 第一人稱「打擊感與揮劍感」核心設計 (Combat Feel & Juice)

本章節為前端 React Three Fiber (R3F) 與 Three.js 繪製層之物理動畫與打擊回饋（Juice）技術規格，旨在於瀏覽器端實現 AAA 級第一人稱打擊回饋。


### 1.1 三段式揮劍曲線（Swing Arc & Anticipation）

揮劍狀態機（State Machine）由 Anticipation (前搖蓄力)、Execution (高速揮斬)、Recovery (後搖收劍) 三個階段構成。


#### 自動連擊招式切換邏輯

根據連續點擊左鍵的計數（Combo Index）與滑鼠 X 軸移動向量自動匹配軌跡：

Combo 1（右斬）：姿態從右側 (x: 0.3, y: -0.2, z: -0.4) 向左弧形掃過，手腕 Roll 軸翻轉 +30°。

Combo 2（左斬）：姿態從左側 (x: -0.3, y: -0.1, z: -0.4) 向右反手掃過，手腕 Roll 軸翻轉 -35°。

Combo 3（斜上挑斬）：從右下方向左上方勾起，Pitch +35°，帶出上揚弧線。

Combo 4（重劈 / Heavy Strike）：高舉過頭 (y: 0.2) 垂直向下轟擊，附加地面微幅震波。


### 1.2 頓幀技術規格（Hit-Stop / Freeze Frame）

當檢測到劍身 Mesh 的 Raycast 或 Capsule 與敵方 Hitbox 發生碰撞時，觸發頓幀機制：

interface HitStopConfig {

lightAttackDuration: number; // 35ms - 50ms

heavyAttackDuration: number; // 80ms - 120ms

timeScale: number;           // 頓幀期間 Delta Time 倍率 (預設 0.0)

}



普通攻擊命中：主邏輯暫停 40ms。Three.js 動畫播放器（AnimationMixer）與敵方 AI 位移暫停，Camera 不停止渲染，保持幀率穩定。

重擊 / 劍技終結技命中：暫停 100ms，並在第 50ms 時對手把觸動或螢幕產生一次矩陣位移。


### 1.3 鏡頭回饋系統（Camera Juice）

微震（Camera Shake）：命中瞬間在 Camera 的 Local Space 引入高頻噪聲（Perlin Noise）。震動向量必須與目前揮劍平面垂直（例：水平斬擊產生垂直 y 軸方向 15Hz 震動，振幅 0.05 單位）。

FOV 動態微調：

發動衝刺 (Dash) 或高階劍技：FOV 在 0.1s 內由 75° 拉寬至 80°（easeOutExpo）。

招式釋放結束：FOV 在 0.3s 內平滑回彈至 75°（easeInSine）。


### 1.4 視覺特效（VFX Specifications）

刀光殘影（Sword Trail Ribbon）：利用 THREE.BufferGeometry 動態生成夾帶 UV 漸層的 Ribbon Mesh，追蹤劍尖與劍柄兩點的歷史座標（維持最近 12 幀）。

普攻：銀白半透明色彩（Alpha 漸隱）。

劍技發動：青藍 (#00F0FF) 或 熾金 (#FFB700) 高亮發光材料（Bloom Pass 增強）。

火屬性附魔：赤紅 (#FF3300) 搭配微粒火花粒子。

受擊閃白與火花：

閃白：怪物 Shader 接收 uHitLighting 訊號，全身 Mesh 覆蓋高純度白光 60ms。

擊退 (Knockback)：受擊瞬間怪物沿玩家視角正前向量（Forward Vector）產生 0.15s 的加速度位移（輕擊 0.5m，重擊 2.0m）。

## 2. 劍技系統（Sword Skills & System Assist）


### 2.1 SAO 風格輔助系統（System Assist）

玩家按住快捷鍵（1 - 4）或長按左鍵蓄力 >0.3s 時，觸發系統輔助發動流程：

鎖定與充能：視角以 0.1s 自動向最近的目標修正 15° 以內角度，劍身亮起對應系別的高亮度光效（Emissive Intensity = 3.0）。

軌跡引導：玩家釋放按鍵後，系統暫時接管玩家手部與視角平移，以高速（正常揮速 200%）自動執行連續斬擊。

路徑修正：若目標移動，連斬過程自動向目標修正座標，防止招式空放。

### 2.3 硬直機制與風險管理（Post-Skill Delay）

收招硬直：高階劍技發動完畢後，玩家角色進入 0.5s 的「系統冷卻硬直（Post-Skill Delay）」，期間無法執行普通攻擊與移動。

取消機制（Cancel Windows）：在劍技最後一擊命中後的 0.1s 內，玩家可透過消耗 15 點體力（Stamina）執行「側步閃避（Step Dodge）」，及時取消後搖硬直。


## 3. 豐富遊戲功能清單 (Feature Roadmap)


### 3.1 角色養成與熟練度系統

基礎屬性：

STR（力量）：增加物理攻擊力與重擊破防值。

AGI（敏捷）：增加攻擊速度、閃避距離與暴擊率。

VIT（體質）：增加 Max HP 與物理/魔法防禦力。

DEX（靈巧）：增加命中率與劍技命中後的 Hit-Stop 時間。

武器熟練度（Mastery）：使用特定武器造成傷害時累積該武器熟練度（0 - 1000）。每提升 100 點解鎖專屬被動技能或新劍技。

### 3.3 生活與輔助系統


#### 藥水調合 (Alchemy)

HP 回復藥：漸進式恢復 HP（5 秒內恢復 40%）。

解毒劑：立即清除中毒狀態並獲得 30 秒抗性。

乙太加速藥水：15 秒內 SP 回復速度提升 100%。


#### 料理系統 (Cooking)

利用野外與怪物掉落食材（如：野豬肉、迷宮苔蘚）於營地烹飪。

提供持續 10 分鐘的增益效果（例：「烤野豬排」：攻擊力 +15%，Max HP +200）。


#### 結晶道具 (Crystals)

轉移結晶：吟唱 1.5s 後立即傳送回最近的安全區主城。

回復結晶：無吟唱時間，立即恢復 100% HP（冷卻時間長）。

解毒結晶：無吟唱時間，淨化全隊負面狀態。


### 3.4 NPC 好感度與夥伴系統 (Affinity & Companion)

好感度階級：陌生 → 友好 → 信賴 → 絆。

提升途徑：每日對話、贈送喜好禮物、完成專屬支線任務。

好感度獎勵：解鎖 NPC 商店專屬折扣、特殊稱號。

AI 夥伴召喚：在單人模式下，可邀請高好感度 NPC 組隊（最多 2 名）。AI 夥伴具備獨立仇恨值、自動使用劍技與發動協同攻擊（Switch）機制。

## 5. Vercel 部署與 localStorage 存檔架構規格


### 5.1 技術棧建議

Core Framework: Next.js 14+ (App Router) 或 Vite + React 18

3D Engine: Three.js + @react-three/fiber (R3F) + @react-three/drei

State Management: Zustand (搭配 persist 中間件)

Styling: Tailwind CSS + Framer Motion (用於 HUD 動態動畫)

Deployment: Vercel (純 Client-side SPA 渲染，Zero Server Overhead)


### 5.2 localStorage 存檔可行性與最佳實踐

可行性分析：完全可行且高效。純前端單人遊戲數據結構輕量，讀取與寫入延遲 < 2ms，且完全免費。

容量管理：localStorage 容量限制約 5MB - 10MB。本遊戲 JSON 數據大小約 20KB - 80KB，僅占用不到 1% 限額。

容錯與防呆機制：

版本控管（Migration Standard）：資料包含 saveVersion，當系統升級新增屬性時，自動執行 Migration 函數進行補全，防止白屏崩潰。

自動備份與雙緩衝寫入：採用 Aetheris_Save_Primary 與 Aetheris_Save_Backup 機制，寫入失敗時自動回滾。

匯入 / 匯出 JSON：開放玩家下載 .json 檔案或貼上 Save String 進行跨裝置轉移。
